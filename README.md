# LooPaint（ルーペイント）

絵を描いて曲を作ろう。アナログに変化するピッチで自由にメロディを描けるシーケンサーもどきです。

## 主な特徴
- **途中再生（シーク機能）**: タイムライン上をクリックして、好きな小節・位置からいつでも再生開始。先頭に戻る「⏮」ボタン付き。
- **可変小節数（1〜32小節）＆ ループ切替**: 従来の短尺ループから、8小節・16小節・32小節の長大な楽曲・メロディ作成まで幅広く対応。「🔁 ループ再生」と「➡️ 1回再生」を切り替え可能。
- **多彩なカラーテーマ（6種類）**:
  - ダーク
  - ライト
  - レトロ
  - パステル
  - サイバー
  - セピア
- **ピアノロールの縦横ズーム＆スクロール**: 時間軸（横）と音高軸（縦）の拡大率スライダー、全体フィットボタン、マウスホイール連動（縦横スクロール・Ctrl+ホイールズーム）。
- **多彩なアコースティック＆エレクトリック楽器音色**:
  - ピアノ (アコースティック打弦)
  - ギター (弦振動物理モデル)
  - 弦楽器 (ストリングスアンサンブル)
  - ブラス (金管楽器)
  - マリンバ (木琴)
  - ベース (重低音スラップ)
  - 宇宙リード (ディレイ＆エコー)
  - 8bit (レトロ矩形波)
- **8オクターブ無段階ピッチベンド**: 自由ペン・スライド直線によるリアルタイムなアナログ周波数追従。
- **連動ドラムマシン**: 16ステップのビートが曲全体で同期。

## 使い方
1. [https://numberzero-0621.github.io/LooPaint/](https://numberzero-0621.github.io/LooPaint/) をクリック。
2. タイムライン上をクリックすると好きな位置から再生できます。
3. 小節数やテーマ、楽器を選び、キャンバスに絵を描くようにメロディを作曲しましょう！
